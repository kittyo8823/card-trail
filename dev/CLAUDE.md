# Card Trail（旧名：カードの塔）

ドット絵のデッキ構築ローグライク（Slay the Spire 風）。`index.html` 1ファイルだけで動く（ビルド不要・外部依存は Google Fonts の DotGothic16 のみ）。
ブラウザで `index.html` を開けば遊べる。（マルチプレイを HTML ファイルで開いたときだけ、通信部品 mqtt.js を CDN から読み込み、無料の公開 MQTT サーバーにつなぐ。）スマホ横向き前提、内部解像度 640×360 の canvas に全部描画している。

## 書き方のルール
- 既存コードは「短い変数名・1行に詰める」スタイル。追加するコードもそれに合わせる。
- UI 文言は落ち着いた、緊張感のある文体（ユーザー指定）。普通の漢字の言葉を使う（戦闘・休憩・筋力・毒・引く・捨てる など）が、難しすぎる漢字は避ける。子ども向けの語尾（〜よ／〜ね／〜しよう！）や、ひらがなだけの言葉は使わない。
- 画面のボタンは毎フレーム `btn()` / `hit()` で登録し直す方式（`btns` 配列）。DOM は使わない。

## キャラと敵の向き
- **向き（ユーザー指定の案A：斜め3/4）**：キャラは右向き、敵は自分の方を向く。`SD` の敵の絵は**すべて右向きの斜め（3/4）で描き**、`SPR` を作るときに `flipC()` で左右反転する（反転しない絵は `NOFL`：pl/si/sm/oji/grim/hori*/skunk/qcube/eye/demon）。描き方：顔・目鼻を進む側（右）へ寄せ、奥の目は細く小さく、手前の腕・翼・肩は大きく、奥側は小さく暗めに一部だけ見せる。武器は前（右）へ構える。新しい敵も右向きで描くこと。
- ボスの必殺演出の位置は反転後の絵に合わせてある（`BFX`：dragon の口 w*.12,h*.31／reaper の刃先 w*.05,h*.2／archdemon(2) の目 w*.44・.53,h*.2／deus の核 w*.475）。絵を描き直したらここも合わせる。睡眠の z は頭の上（behemoth は左寄り）。

## 主なグローバル状態
- `S` 現在の画面: `title / lib / select / neow / map / battle / reward / rest / event / shop / pick / conf / help / act / over / win`。切り替えは `go(s)`（BGMも切り替わる）
- `P` ラン全体: `cls`キャラ番号, `hp/mhp`, `gold`, `deck:[{i:カード番号,u:強化済み}]`, `relics`, `act`層, `pot`, `ps`ポーション枠
- `B` 戦闘: `en`敵, `hand/dr/dis/ex`手札・山札・捨て札・廃棄, `me`エナジー, `blk`, `ph`（`p`自分 / `x` / `e`敵 / `V`勝ち / `L`負け / `D`）
- `PS` 戦闘中の自分のステータス・パワー（`str`, `weak`, `ki`, `brut` など）
- セーブ: `go('map')` / `go('act')` のたびに `saveRun()` が `P`・`MP`・`CUR` を localStorage（`cardtower_save`）へ保存。`over`/`win` で削除。タイトルの「つづきから」→ `loadRun()`。**`P` に入れる値は JSON にできるもの（数値・文字列・配列・普通のオブジェクト）だけにする。**
- 音: スマホで画面を離れて戻ると AudioContext が止まるので、`visibilitychange` やタップのたびに `initAudio()` で再開し、だめなら `newAC()` で作り直して BGM を続きから鳴らす。
- 層は全3層。ボス撃破で `act` 画面 → `startAct()` で次の層へ。第3層ボス撃破で `win`。
- スコア用に `P.kills/elites/bosses/mx/perf/ge/killer` を記録し、`score()` が勝利／敗北画面で集計（ベストは localStorage）。
- マップの一番左（`MX(-1)`）は第1層では「？？？」マス（宙に浮かぶ近未来の立方体 `SPR.qcube`＝`neow` 画面。原作のネオーと同じ配置：左に自分、右に巨大な立方体と回る光の輪、横に吹き出し（1文字ずつ表示 `NE.t0`）、左下に選択肢。背景 `NEB`。ユーザー指定で悪魔から変更）。`P.nw` が 0 の間は悪魔マスしか選べず、契約すると 1。第2層以降は「入口」の印だけ。
- `MP` マップ：`MP[階][段]`（段は0〜4、部屋がない所は null）。`genMap()` が6本の道をランダムに曲げながら引く（交差なし、どの道も15マス＝`LAST`。Ver2.53 で13→15。古いセーブや届いた地図は `fixL()` が `MP.length-1` に合わせる）。部屋は `{t:種類,cn:次の階でつながる段,dx,dy:描画のずれ}`、最後の階はボス1つ。通った部屋は `P.path`（'階,段' の配列）。最初の部屋は2〜3個。同じ階の部屋は縦一列（`dx:0`）。地図は横長（幅 `MSW`、列の間隔 `MCW`、列の位置 `MX(f)`）で、`MSC` が横スクロール量（ドラッグ／ホイールで動く。マップに入ると現在地が見える位置へ）。描画は `drawMap()`、層ごとの地図の見た目は `MTH`／`mpanel()`。

## カードデータのキー（`C` の各要素）
`n`名前 `t`種類(0攻撃/1スキル/2パワー) `c`コスト(-1はX) `r`レア度(-2小ナイフ/-1初期/0/1/2) `k`キャラ(0ユウキング/1坂井/2坪内丸/3名無し/4ホーリー大輔＝隠し/5無色)
効果: `a`単体ダメ `h`回数 `aa`全体ダメ `b`ブロック `dr`ドロー `en`エナジー `vu/wk`弱体/脆弱 `vuA/wkA`全体 `ps/psA`どく `st/ts`ちから/一時ちから `hp`HPコスト `x`廃棄 `X`Xコスト
`pw`パワーの種類と `v`その量（**パワーには必ず `v` を付ける**。`barr` だけ例外）
朧丸: `ia`居合ボーナス `kg`気+ `kx`気×ダメ `kc`気を使い切る `ke/kd`倒すとエナジー/ドロー `ct`反撃
- 説明文は `dl(card)` がキーから自動生成する。新しいキーを足したら `dl` にも説明を足す。
- 新しいパワー（`PS` のキー）を足したら、戦闘画面の状態表示 `PSD`（ラベル・色・タップ時の説明）にも1行足す。
- 黒いカード: `t:3` 状態異常（敵の行動 `sc:[カード名,枚数]` で戦闘中だけ捨て札に混ざる）、`t:4` 呪い（デッキに残る。`randCurse()`）。`r:-3/-4,k:9` なので報酬・お店には出ない。キー `eth` エセリアル, `bn` 手札で終わるとダメ, `rg` HP減, `cw` 脆弱, `pn` 使うたびHP減, `art` 絵。強化可否は `canUp()`。
- 強化は `up(card)` が自動計算（`a/aa/b` は+30%、`UPK` のキーは+1、それ以外はコスト-1など）。パワーの `v` は4以上なら約+30%。「あるかないか」だけのパワー（`BPW`：bers udy ftw pmul fz ct2 rech ms2 msf、強すぎる egy echo）は数値でなくコスト-1（ユーザー指定：強化で何も変わらないパワーを無くす）。
- カード番号はインデックスなので、**`C` の途中に挿入しない**（末尾に追加する）。`SHIV=46` は小ナイフの番号。

## タイトル画面
- ゲーム名は「Card Trail」。タイトル文字は Google Fonts の Press Start 2P。
- `drawTitle()`：夜の丘を3人の影が塔へ歩く構図で、`TVD` の4種類（月夜／黄昏／嵐／星座）から、タイトルに切り替わるたびにランダムで選ぶ（直前と同じは出さない。`pickTitle()` は `draw()` で S が title に変わった瞬間に呼ぶ）。動かない空・丘・塔は `tPre()` で一度だけ描いて `TCA` にキャッシュ。

## キャラ・イベント
- キャラは `CH`：0=ユウキング（筋力・ブロック）、1=坂井（毒・小ナイフ）、2=坪内丸（気・居合）。名前はユーザー指定。
- キャラ選択画面 `drawSelect()` は1人ずつスポットライトで見せる形（ユーザーが案Aを採用）。新キャラは `CH` に `{n,hp,rel,s:絵,col,dk,lt:イメージカラー,dk:デッキ,dkt,st,key}` を足し、`SD` に絵、`HELP_T/HELP_X` に説明タブを足せば、選択画面（顔アイコンの並びも自動で縮む）に出る。切り替えは ◀▶・スワイプ・顔アイコン・←→キー（`selGo()`）。
- イベントは `EVS`（`{t:名前,im:絵の名前,x:[本文],ch:[[選択肢,関数]]}`）。名前は「本家にありそうで無い」オリジナル。絵は `EIM.<名前>=[描画関数(38x34),背景上色,背景下色]` を足すと `EIC` に4倍で作られ、`drawEvent()` の左側に出る。

## 敵・レリック
- ボスの行動に `nm`（技名）と `fc`（色）を付けると「必殺」扱い：予告に「必殺」が点滅し、敵ターンで約1.3秒ため演出（`B.sp`）→ 着弾 `fx 'bz'`。演出はボスごとに `BFX.<敵名>={tn:暗転色,ch(o):ため,hit(f,p):着弾,lift?}` に書く（新ボスを足したら BFX にも足す。無ければ deus の演出を使う）。
- レア度2のカードを使うと `fx 'rx'`（`rxDraw`）：種類 a=単体攻撃 / aa=全体 / p=パワー / s=スキル、専用 cut・god・moon。色はキャラごと（`play()` 内の pal）。文字のカットインは出さない（ユーザー希望）。
- 通常の敵（`el` なし）は `fight()` で HP を 1.75 倍にしている（ユーザー調整済み。エリート・ボスはそのまま）。
- カードの見た目はA案（ユーザー採用）：種類色の枠（レアは金）、上に名札、左上にひし形のコスト、中央に絵の窓、その下に種類名（8px）と説明。説明の行数で絵の窓の高さが変わる（`AH`：1行44／2行40／3行32／4行以上26、4行以上は9px）。名前は `nfs()` で枠に収まる大きさに縮める。
- レアカードは `card(x,y,o,dim,gl,pv)` の `gl=1`（報酬・お店の選ぶ場面）のときだけ光る。どこでも名札・枠・絵の縁が金色。
- ダメージ予測：戦闘中は `pvw(o,敵)` で筋力・脆弱・弱体・居合・気・ペン先などを `play()` と同じ式で計算し、`card()` の `pv` と `dl(c,pv)` に渡す。元より高い数字は緑、低い数字は赤。対象はドラッグ中に重ねた敵、なければ敵が1体のときだけその敵。全体攻撃は全員が弱体のときだけ1.5倍。**`play()` のダメージ計算を変えたら `pvw()` も合わせる。**
- 敵の行動で自分にかかる脆弱・弱体は、その敵ターンの終わりには減らない（`B.jw/B.jv`。原作と同じく次の自分のターンに効く）。弱体と攻撃を同時に行う行動は、攻撃のあとに弱体をかける（予告どおりのダメージ。ユーザー指定）。
- 状態の名前：`vuln`（受けるダメージ1.5倍）＝**弱体**、`weak`（与えるダメージ0.75倍）＝**脆弱**（ユーザー指定で入れ替え済み）。
- 敵 `E.<名前>={n,hp:[最小,最大],mv:[行動...],el:1エリート/2ボス}`。行動は `mv` を順番にループ。行動キー `a h b st wk vu ps`。絵は `SD.<同じ名前>` が必要。
- レリックの右下の数字（原作どおり、戦闘中だけ）：`relCnt(k)` が返す。ペン先＝攻撃回数%10、苦無の束＝攻撃回数%3、幸せの花＝ターン%3。1度きりのお守りは使うと半透明（`P.amu`）。回数で発動するレリックを足したら `relCnt` にも足す（ユーザー指定）。

## 手触り・演出の作り込み（ユーザー指定）
- ヒットストップ `hstop(ms,dl)`：敵に14以上で65ms・25以上で100ms、自分が12以上受けると55〜90ms、`loop()` が `HSU` まで `update()` を止める（描画は続く）。

## 姿・状態が変わった直後は攻撃しない（ユーザー指定）
- 変身 `tfE()`：最初の行動は強化（筋力+3・ブロック12。`e.i=-1` にして本来の行動を飛ばさない）。
- 寄生 `dspE()` で出た寄生虫2匹・分裂 `splE()` の分裂片：最初の行動は `stn`（行動不能＝混乱）。
- 連動の腕 `pr`：片方が壊れた直後の残りの腕は「激昂」（ブロック15）で、攻撃しない（`x.i--` で本来の行動を後にずらす）。
- 睡眠中にダメージで起こされた敵（眠れる巨獣・休眠機兵）：次の行動は `stn`（寝ぼけている）。
- 召喚 `spawnE()` の敵は出てきたターン行動しない（`nw`）。実験体の再起動は起き上がる行動自体が攻撃なし。
- 新しい「変わる」敵を足すときも、変わった直後の行動は攻撃にしない。`i` が負（変わった直後の特別な行動を待っている）の間は、敵ターン終わり・ターン開始で次の行動 `it` を上書きしない（敵ターン中に変身したときの落ち方を直した）。

## マルチプレイ（協力・最大4人。スレスパ2の仕組みに寄せた。ユーザー指定で専用サーバーは使わない）
- 入口：タイトルの「マルチプレイ」→ `mpm`（説明・部屋を作る／入る）→ `mpj`（4桁の部屋番号のキー入力）→ `mpn` 名前の入力（作る人も入る人も必須、10文字まで。日本語入力のためこの画面だけ `<input>`＝`NMI`（と「決定」ボタン）を画面の上端中央に固定して出す（canvas に合わせて動かすと、スマホでキーボードが出たとき位置がずれるため。iOS の拡大を防ぐため文字は18px）。表示の出し入れは `nmPlace()`。`nmClean()` で制御文字を除く。前回の名前は localStorage `cardtower_nm`）→ `mpl` 待合室（各自キャラを選ぶ。ホストがアセンションと出発）。状態は `MPR`（`me` 自分のid、`host`、`lob` 参加者、`pl` 出発時の並び、`votes`、`seed`）。`MPON()`＝出発後。
- 仕様：マップ・敵は共通、デッキ・ゴールド・レリック・ポーションは各自。敵のHPは人数で 2人2.25倍・3人3.55倍・4人5.05倍（`mpHpM`。途中で復活する実験体も同じ倍率。ユーザー指定）。HPは必ず整数に丸める（小数は出さない）。敵の攻撃・デバフ・状態異常カードは全員に届く（`囮` を使った人がいればその人だけ）。全員がターン終了（`B.dn`）すると敵のターン（`mpEnemy()`）。HP0の人は戦闘不能（`B.down`）で、味方が勝てば戦闘後にHP10%で起き上がる。全員倒れたら敗北。進路は投票（`mpVote`→ホストの `mpResolve` が多数決、同数はランダム）。ショップ・休憩・イベント・報酬・？？？は各自の画面で行う。ホーリー大輔の30分制限は無し。救済の「前のマスに戻る」とセーブは無し。最後の虚空の眼は各自ひとりで戦う。
- 戦利品の取り忘れ：マルチでも地図から「◀ 前のマスに戻る」で取りに戻れる（各自の持ち物なので同期不要。地図に戻ると `sync` で送り直す）。ただし進路を投票したあとは出さない（投票時に送った P とずれるため）。
- 同期の方式（ロックステップ）：全員の画面が全員分の戦闘を計算する。戦闘中の操作（カード `['p',手札番号,敵,カード番号]`／ターン終了 `['e']`／ポーション `['u'|'x',番号,種類]`／捨てる選択 `['d',…]`）は `mpIn()` でホストへ送り、ホストが通し番号を付けた `ord` を全員に配り、全員が `mpApply()` で同じ順に適用する（ホストの操作はその場で確定）。敵のターン中に届いた操作は待ち、遅れた画面は `mpCatch()` で早送りする。ホスト以外は確定まで公開サーバーを2往復するので、カード・ポーション・捨てる選択は**予測**で即座に効果まで適用する（ターン終了 `e` だけは予測せず `B.dnp` で「待っている」表示）：`mpIn()` が `MPB.pred` に操作、`MPB.snaps` にその直前の状態（`mpSnap()`＝SB・全員の P/PS/B・乱数の状態 `MPB.rng.s` の深いコピー）を積み、`mpApply()` で手元に適用する。確定（`mpConf()`）が自分の先頭の予測と同じならそのまま捨てるだけ。他の人の操作が先に確定したら `mpRest(snaps[0])` で巻き戻し、確定分を適用し、残りの予測を `QT=1`（演出・効果音・台詞を出さない）でやり直す。確定分で全員のターンが終わったら残りの予測は捨てる。予測が残っている間は敵のターン開始（`mpEnemy`）・勝利後の画面遷移・全滅の遷移を待たせる。操作の時刻 `t` はクライアントが付け、ホストはそれをそのまま `ord` に使う（`MPB.now` を全員で一致させるため）。手札番号が合わないときは同じカード番号の最初の1枚を使う（全員が同じ規則で適用するので一致する）。ホストの画面だけは従来どおり `o.pend` で飛ばす。
- 決定性のための約束：戦闘の乱数は `R()`（`RNG` があれば戦闘ごとの種から作った `mpRng`）。**描画・演出・音で `R()/RI()/pk()/shuf()` を使わない**（`Math.random()` を使う。使うとずれる）。戦闘中の `setTimeout`・`Date.now()` も使わない（ホーリーの経過時間は `MPB.now`＝操作に付いたホストの時刻）。進路を決めた `node` の種で `enter()` を、`MPR.seed` で各層のマップを作る。
- 文脈の切り替え：プレイヤーごとに `PL[k]={P,PS,B}`。`useP(k)` で `P/PS/B` と `CK` を切り替える（`LK`＝自分）。各自の `B` の共有項目（`en turn ph ei et sp bn vt kind boss`）は `SB` を指すゲッター。`mpEach(f)`／`mpOthers(f)` で全員／他の味方に適用。`fxs()` は味方側の演出を各自の位置（`PPX(k)`）へずらし、他人の画面下部の演出は出さない。`say()` は自分の文脈だけ。
- 通信：claude.ai の `room` capability（公開時に `capabilities:{room:{topics:{mp:'interact'}}}`）。部屋は全員共通のロビーで、メッセージに部屋番号 `c` を付けて区別。`emit` できない閲覧者は `presence` の送信箱（`NET.ob`、4KiB以内）で送る。room が無い環境（ファイル直開き・テスト）は `BroadcastChannel`（同じブラウザの別タブだけ）。1000文字超は分割（`ty:'ck'`）。ホストが抜けると残りの人が引き継ぐ（Ver1.88）。抜けた人は75秒で退出扱い。待合室の2行目に通信の状態（オンライン接続中か・このページを開いている他の画面の数・送信／受信の回数・presence 送信か・エラー）を出す。room が使えない開き方なら理由（`NET.why`）を出す。接続前のメッセージは `NET.q` にためて接続時に送る（room は未接続の emit を黙って捨てるため）。
- 通信の順番（`netOpen()`）：①claude.ai の room → ②無料の公開 MQTT サーバー（`mqOpen()`：`MQB` の hivemq／emqx／mosquitto を順に試す。mqtt.js 5.10.1 を `MQJ` の jsdelivr→unpkg から必要なときだけ読み込む。話題は `cardtrail/v1/部屋番号`、自分の送信は `NET.mid` で無視。誰でも読める公開サーバーなので個人情報は送らない）→ ③BroadcastChannel。部屋番号は6桁（偶然かぶりにくくするため）。テストでは `window.__MQB` で中継先を差し替えられる（手元に aedes＋ws のサーバーを立てて試した）。
- 協力カード（`k:7`、マルチ中だけ報酬12%・ショップの無色枠に出る。カード一覧に「協力」タブ）：援護 `abk`／鼓舞 `aen`／連携攻撃 `cmbA`（他の味方がこのターン攻撃済みなら2倍、`SB.atk`）／分け前 `aheal`（HP割合が最も低い味方）／声援 `adr`／囮 `tnt`（`PS.tnt`）／共鳴 `aaP`（全体攻撃×戦える味方の数）／蘇生の祈り `rev`。
- 名前（`MPR.pl[k].nm`、`mpNm(k)`）は待合室・マップの仲間の欄・戦闘のキャラの頭上（小さい札）に出す。
- 終了画面（敗北・勝利）の「待合室に戻る」＝`mpBackLobby()`：同じ部屋番号のまま待合室へ。先に戻った人の hello はホストが `MPR.pend` に覚えておき、ホストが戻ったときに参加者に入れる。抜ける人は「タイトルへ」、新しい人は同じ番号で入れる。
- 表示：戦闘の味方はひし形（ユーザー指定）：自分が一番手前の中央下（普段の大きさ・足元にHPバー）、他の人は左・右・奥に半透明（奥ほど小さく、頭上に細いHPバーと色の印＝`PCOL`）。位置は `PSL(k)`／`PPX`／`PPY`、描画は `mpDrawPlayers`（名無しの本は縮小）、マップは投票の印と下の仲間の状態（`mpParty`）。

## カードの動き（戦闘）
- 手札の各カード（`B.hand` の要素）は描画位置 `o.hx/o.hy/o.hs` を持ち、毎フレーム目標位置へ近づく。`drawC()` で引いたカードは `o.ht`（0.08秒ずつずらした出現時刻）まで隠れ、山札 `DP` から滑り込む。生成カード（小ナイフ等）は画面中央から出る。
- 手札から離れるカードは `cFly(o,種類,x,y,遅延)` で `B.fly` に積み、`drawFly()` が描く：`use` 一瞬白く光って縮み、細い光の線（ベジェ曲線の軌跡）になって弧を描き捨て札へ（原作風・ユーザー指定）、`pw` 上へ光って消える、`ex` 中央で燃え尽きる、`dis` 捨て札へ（ターン終了・捨てる）、`sh` 山札の補充（裏向きで捨て札→山札）。位置は `DP`（山札）/`DSP`（捨て札）。
- 拡大縮小・回転して描くときは `cardAt(o,中心x,中心y,倍率,回転,透明度)`（o=null で裏面）。
